Lanaia Coin (LNC)

**Lanaia Coin** est un projet de cryptomonnaie décentralisée basée sur Proof-of-Work. Conçue pour une émission monétaire transparente et un minage accessible à tous.

Caractéristiques Principales

- **Symbole** : LNC
- **Offre Cible Maximale** : 21,000,000 LNC
- **Consensus** : Proof-of-Work (RandomX)
- **Temps de Bloc** : 120 secondes
- **Halving** : Tous les 1,050,000 blocs (~4 ans)
- **Récompense Initiale** : 10 LNC par bloc

Documentation

- [Whitepaper V1](./LNC_WHITEPAPER_V1.md) - Spécifications techniques et calendrier
- [Économie Monétaire](./LNC_ECONOMICS.md) - Modèle économique et émission

Prototype

Le dossier `prototype/` contient un simulateur pour tester la logique d'émission et de halving de LNC.

Statut

**V1 Spécification** - Le protocole est en phase de spécification. 
Le mainnet sera lancé après finalisation de la V2 technique et audit de sécurité.

Avertissement

**LNC n'a aucune valeur monétaire garantie tant que le mainnet n'est pas lancé.** Le développement est en cours.
